# LLM Wiki：資安產業研究入門

本 Wiki 由八篇官方來源整理為六篇互相關聯的概念條目，作為十八頁 HTML 簡報的知識來源。

## 概念條目

- [企業風險與 CSF](risk.md)：資產、風險與六項核心功能。來源 S01。
- [端點與 EDR](endpoint.md)：裝置活動、偵測、調查與回應。來源 S04。
- [身分、IAM 與 MFA](identity.md)：驗證、授權與抗釣魚驗證。來源 S03、S05。
- [網路防護與應用辨識](network.md)：應用流量與解密政策條件。來源 S06。
- [零信任與多層防護](zero-trust.md)：不依網路位置給予隱含信任。來源 S02、S04、S05、S06。
- [從公司產品到財報指標](metrics.md)：營收、ARR、FCF 及比較口徑。來源 S07、S08。
